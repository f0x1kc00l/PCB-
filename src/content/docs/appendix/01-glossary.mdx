Глоссарий содержит 127 терминов курса. Английский вариант дан так, как он встречается в интерфейсе Altium Designer и в англоязычных даташитах. Ищи нужное слово через поиск по странице браузера: <kbd>Ctrl</kbd>+<kbd>F</kbd>.

| Термин | English | Что это |
|---|---|---|
| **Автотрассировщик** | Autorouter | программа, автоматически прокладывающая дорожки по заданным правилам |
| **Амперметр** | Ammeter | прибор для измерения тока; включается в разрыв цепи |
| **Амплитуда** | Amplitude | наибольшее отклонение сигнала от среднего (нулевого) уровня |
| **Аннотация** | Annotation | автоматическая расстановка позиционных обозначений (R1, C2…) на схеме |
| **Анод** | Anode | вывод диода, в который втекает прямой ток |
| **База** | Base | управляющий вывод биполярного транзистора |
| **Библиотека компонентов** | Component library | набор символов, посадочных мест, 3D-моделей и параметров компонентов |
| **Биполярный транзистор** | Bipolar junction transistor, BJT | транзистор, у которого ток коллектора управляется током базы |
| **Вольт-амперная характеристика (ВАХ)** | I–V characteristic | график зависимости тока через элемент от напряжения на нём |
| **Вольтметр** | Voltmeter | прибор для измерения напряжения; подключается параллельно участку цепи |
| **Время нарастания** | Rise time | время, за которое фронт сигнала проходит от 10 % до 90 % размаха |
| **Входное сопротивление** | Input impedance | сопротивление, которое вход схемы или прибора представляет для источника сигнала |
| **Выводной монтаж** | Through-hole technology, THT | монтаж компонентов с выводами, вставляемыми в отверстия платы |
| **Выпуск проекта** | Project release | формирование неизменяемого набора выходных данных для производства |
| **Выравнивание длин** | Length tuning | удлинение дорожек (меандрами), чтобы задержки сигналов совпадали |
| **Выходное сопротивление** | Output impedance | внутреннее сопротивление источника сигнала со стороны выхода |
| **Гербер-файл** | Gerber file | стандартный формат описания рисунка слоёв платы для производства |
| **Действующее значение** | RMS value | постоянное напряжение, выделяющее на резисторе ту же мощность, что и переменное |
| **Делитель напряжения** | Voltage divider | два резистора последовательно; выход снимается с точки между ними |
| **Диод** | Diode | полупроводниковый прибор, проводящий ток в одном направлении |
| **Дифференциальная пара** | Differential pair | две дорожки, передающие сигнал в противофазе (например, USB D+/D−) |
| **Диэлектрическая проницаемость** | Dielectric constant, Dk (εr) | свойство изолятора, влияющее на ёмкость и волновое сопротивление дорожек |
| **Допуск** | Tolerance | допустимое отклонение реального значения параметра от номинала |
| **Дорожка** | Track, trace | проводник на слое меди печатной платы |
| **Зазор** | Clearance | минимальное расстояние между проводящими объектами разных цепей |
| **Затвор** | Gate | управляющий электрод полевого транзистора |
| **Земля (общий провод)** | Ground, GND | общая точка отсчёта потенциала в схеме, принятая за 0 В |
| **Иерархическая схема** | Hierarchical design | схема, разбитая на листы, связанные через символы листов и порты |
| **Импеданс волновой** | Characteristic impedance | сопротивление линии передачи для бегущей волны; зависит от геометрии дорожки и стека |
| **Индуктивность (катушка)** | Inductance (inductor) | свойство (и элемент) запасать энергию в магнитном поле |
| **Исток** | Source | электрод полевого транзистора, от которого отсчитывается напряжение затвора |
| **Источник напряжения** | Voltage source | источник, поддерживающий заданное напряжение независимо от нагрузки (в идеале) |
| **Источник тока** | Current source | источник, поддерживающий заданный ток независимо от нагрузки (в идеале) |
| **Катод** | Cathode | вывод диода, из которого вытекает прямой ток; на корпусе отмечен полосой |
| **Класс цепей** | Net class | именованная группа цепей, к которой применяют общие правила проектирования |
| **Коллектор** | Collector | вывод биполярного транзистора, через который течёт основной (управляемый) ток |
| **Компонент** | Component | элемент схемы вместе со всеми его моделями: символом, посадочным местом, 3D, параметрами |
| **Конденсатор** | Capacitor | элемент, накапливающий заряд; две обкладки, разделённые диэлектриком |
| **Контактная площадка** | Pad | участок открытой меди, к которому паяется вывод компонента |
| **Контур платы** | Board outline, board shape | внешняя граница печатной платы |
| **Короткое замыкание** | Short circuit | соединение цепей с очень малым сопротивлением, не предусмотренное схемой |
| **Корпус** | Package | конструктивное исполнение компонента: 0805, SOT-23, SOIC-8, QFN и т.п. |
| **Коэффициент заполнения** | Duty cycle | доля периода, в течение которой импульсный сигнал находится в высоком уровне |
| **Меандр** | Square wave; meander (trace) | 1) прямоугольный сигнал с D = 50 %; 2) змейка дорожки для выравнивания длин |
| **Медный слой** | Copper layer | слой платы с рисунком проводников |
| **Метка цепи** | Net label | текстовая метка, задающая имя цепи; одноимённые метки соединены |
| **Механический слой** | Mechanical layer | слой платы для размеров, контура, вспомогательной графики |
| **Микроконтроллер** | Microcontroller, MCU | микросхема с процессором, памятью и периферией на одном кристалле |
| **Микросхема** | Integrated circuit, IC | много элементов схемы на одном кристалле в общем корпусе |
| **Мощность** | Power | энергия, выделяемая или передаваемая за единицу времени; P = U·I |
| **Мультивибратор** | Astable multivibrator | генератор прямоугольных импульсов на двух ключах с перекрёстными RC-связями |
| **Мультиметр** | Multimeter | прибор для измерения напряжения, тока, сопротивления и прозвонки |
| **Нагрузка** | Load | элемент или цепь, потребляющая ток от источника |
| **Напряжение** | Voltage | разность потенциалов между двумя точками; работа по переносу единичного заряда |
| **Напряжение холостого хода** | Open-circuit voltage | напряжение на выходе источника без нагрузки |
| **Нарушение** | Violation | несоблюдение правила проектирования, найденное при проверке |
| **Номинал** | Value | номинальное значение параметра компонента: 10 кОм, 100 нФ |
| **Обратная связь** | Feedback | подача части выходного сигнала обратно на вход схемы |
| **Обратный диод** | Flyback diode | диод параллельно индуктивной нагрузке, гасящий выброс при выключении |
| **Операционный усилитель (ОУ)** | Operational amplifier, op-amp | дифференциальный усилитель с очень большим коэффициентом усиления |
| **Отверстие металлизированное** | Plated through-hole, PTH | отверстие с медной гильзой, соединяющее слои |
| **Отверстие неметаллизированное** | Non-plated hole, NPTH | отверстие без металлизации, например крепёжное |
| **Панелизация** | Panelization | размещение нескольких плат на общей заготовке для производства и сборки |
| **Панель (Altium)** | Panel | окно интерфейса Altium: Projects, Components, Properties, Messages… |
| **Паяльная маска** | Solder mask | защитное покрытие платы с окнами под площадки |
| **Паяльная паста** | Solder paste | смесь порошка припоя и флюса, наносимая через трафарет |
| **Перекрёстное выделение** | Cross-probing, cross-select | выделение объекта в схеме вместе с его отражением на плате и наоборот |
| **Переходное отверстие** | Via | металлизированное отверстие для перехода проводника между слоями |
| **Перечень элементов** | Bill of materials, BOM | список компонентов изделия с количествами и параметрами |
| **Период** | Period | время одного полного цикла периодического сигнала |
| **Печатная плата** | Printed circuit board, PCB | основание с проводящим рисунком, на котором монтируются компоненты |
| **Позиционное обозначение** | Designator, reference designator | уникальное имя компонента в схеме: R1, C3, U2 |
| **Полевой транзистор (МОП)** | MOSFET | транзистор, проводимость канала которого управляется напряжением на затворе |
| **Полигон** | Polygon pour, copper pour | область меди, заливаемая с учётом зазоров, обычно земля |
| **Порт** | Port | объект схемы, соединяющий цепи между листами иерархического проекта |
| **Порт питания** | Power port | символ цепи питания или земли (GND, +5V); одноимённые порты соединены |
| **Посадочное место** | Footprint, land pattern | рисунок площадок, контура и маркировки компонента на плате |
| **Правило проектирования** | Design rule | ограничение для платы: ширина, зазор, размеры отверстий и т.п. |
| **Предохранитель** | Fuse | элемент, разрывающий цепь при превышении тока |
| **Препрег** | Prepreg | стеклоткань с неотверждённой смолой, склеивающая слои многослойной платы |
| **Принципиальная схема** | Schematic diagram | чертёж, показывающий элементы и электрические связи между ними |
| **Проверка правил проектирования** | Design rule check, DRC | автоматическая проверка платы на соответствие правилам |
| **Проверка электрических правил** | Electrical rule check, ERC | автоматическая проверка схемы на ошибки соединений |
| **Проводимость** | Conductance | величина, обратная сопротивлению: G = 1/R |
| **Проект** | Project | набор связанных документов изделия: схемы, плата, выходные данные (.PrjPcb) |
| **Прозвонка** | Continuity test | проверка наличия электрического соединения между точками |
| **Рабочее пространство** | Workspace | облачное хранилище Altium 365 для проектов, компонентов и выпусков |
| **Размах** | Peak-to-peak | разность между максимумом и минимумом сигнала; для синуса — 2A |
| **Разъём** | Connector | электромеханический компонент для разъёмного соединения цепей |

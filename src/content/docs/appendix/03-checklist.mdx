Пройди по списку перед каждым заказом. Каждая галочка — ошибка, которую кто-то уже оплатил своими деньгами и временем. Пункты сгруппированы по этапам; в скобках — урок, где тема разобрана подробно.

<Callout type="warning">
  Числа в этом списке — ориентиры. Окончательные значения минимальной ширины, зазора, диаметра отверстий и пояска
  берутся из **технологических норм конкретного производителя**: у каждого завода они свои и зависят от класса точности
  и цены. Например, JLCPCB указывает для 1–2-слойных плат минимальную ширину и зазор 0,10 мм и минимальное отверстие
  0,15 мм (по их странице возможностей), но для первой платы лучше брать с запасом.
</Callout>

## 1. Схема

- [ ] Все компоненты имеют позиционные обозначения без повторов и пропусков — аннотация выполнена ([3.3](../../m03-circuits/03-reference-designators/), [7.3](../../m07-multivibrator/03-schematic-capture/)).
- [ ] У каждого компонента правильное посадочное место, и корпус совпадает с тем, что ты реально купишь ([2.10](../../m02-components/10-packages/), [8.1](../../m08-libraries/01-component-anatomy/)).
- [ ] Цепи питания и земли названы единообразно (GND, +3V3, +5V), нет «висящих» портов питания ([1.1](../../m01-electricity/01-current-voltage/)).
- [ ] У каждой микросхемы есть развязывающие конденсаторы по питанию ([3.7](../../m03-circuits/07-decoupling/)).
- [ ] Номиналы и мощности резисторов проверены расчётом ([1.3](../../m01-electricity/03-power/)).
- [ ] Индуктивные нагрузки (реле, моторы) защищены обратным диодом ([3.5](../../m03-circuits/05-transistor-switch/)).
- [ ] Проверка электрических правил (ERC) пройдена, каждое оставшееся предупреждение осознанно ([7.7](../../m07-multivibrator/07-drc/)).

## 2. Библиотеки и посадочные места

- [ ] Посадочные места сверены с чертежом корпуса в даташите: шаг, размеры площадок, первый вывод ([2.11](../../m02-components/11-datasheet/), [8.3](../../m08-libraries/03-footprint-manual/)).
- [ ] Площадки соответствуют IPC-7351 или рекомендациям производителя компонента ([8.4](../../m08-libraries/04-ipc-wizard/)).
- [ ] Ключ первого вывода и полярность (диоды, светодиоды, электролиты, микросхемы) видны на шелкографии.
- [ ] Распиновка транзисторов (E-B-C) совпадает с конкретной моделью в корпусе: у разных производителей она бывает разной.
- [ ] Отверстия под выводные компоненты больше диаметра вывода с технологическим запасом.

## 3. Плата: размещение и трассировка

- [ ] Контур платы замкнут и совпадает с механикой: корпус, крепёжные отверстия, разъёмы ([7.5](../../m07-multivibrator/05-pcb-document/)).
- [ ] Разъёмы и органы управления стоят у края и доступны ([5.2](../../m05-pcb-design/02-placement/)).
- [ ] Ширина силовых дорожек рассчитана по току ([5.4](../../m05-pcb-design/04-trace-width/)).
- [ ] Зазоры соответствуют напряжению и нормам производителя ([5.5](../../m05-pcb-design/05-clearance/)).
- [ ] Развязывающие конденсаторы стоят рядом с выводами питания, петли тока короткие ([5.7](../../m05-pcb-design/07-power-decoupling/)).
- [ ] Полигон земли залит заново после последних изменений, нет изолированных «островков» меди ([5.6](../../m05-pcb-design/06-pours-ground/)).
- [ ] Горячие компоненты имеют медь для теплоотвода ([5.8](../../m05-pcb-design/08-thermal/)).
- [ ] Не осталось неразведённых соединений (линий связи).

## 4. Проверка правил (DRC)

- [ ] Правила настроены по нормам выбранного производителя, а не по умолчанию ([7.4](../../m07-multivibrator/04-design-rules/)).
- [ ] DRC пройден без нарушений; исключения обоснованы и записаны ([7.7](../../m07-multivibrator/07-drc/)).
- [ ] Схема и плата синхронизированы: после последних правок схемы плата обновлена.

## 5. Шелкография и маркировка

- [ ] Надписи не лежат на площадках и не перекрыты компонентами.
- [ ] Высота и толщина шрифта не меньше минимальной по нормам производителя.
- [ ] На плате есть название, версия (ревизия) и дата — пригодится через полгода.
- [ ] Полярность и первый вывод видны после установки компонентов.

## 6. Выходные файлы

- [ ] Gerber всех нужных слоёв: медь, маска, шелкография, паста (если нужна сборка), контур ([10.2](../../m10-manufacturing/02-gerber-odb/)).
- [ ] Файлы сверловки: металлизированные и неметаллизированные отверстия, единицы и формат согласованы с Gerber ([10.3](../../m10-manufacturing/03-nc-drill/)).
- [ ] Gerber открыт в независимом просмотрщике, все слои совпадают друг с другом ([10.8](../../m10-manufacturing/08-gerber-viewer/)).
- [ ] Для сборки: перечень элементов (BOM) с точными артикулами и файл координат (Pick&Place) ([10.4](../../m10-manufacturing/04-bom/), [10.5](../../m10-manufacturing/05-pick-place/)).
- [ ] Чертёж платы с толщиной, материалом, покрытием и техтребованиями ([7.8](../../m07-multivibrator/08-draftsman/), [10.7](../../m10-manufacturing/07-draftsman-eskd/)).
- [ ] Выходные данные собраны через Output Job и выпущены одним комплектом ([10.6](../../m10-manufacturing/06-output-job/)).

## 7. Заказ

- [ ] Параметры заказа совпадают с проектом: число слоёв, толщина платы, толщина меди, цвет маски, финишное покрытие ([4.5](../../m04-pcb-basics/05-mask-silk-finish/), [10.9](../../m10-manufacturing/09-ordering/)).
- [ ] Размер платы в заказе совпадает с контуром.
- [ ] Предпросмотр на сайте производителя проверен глазами.
- [ ] Компоненты для сборки есть в наличии, сроки поставки устраивают.
- [ ] Сохранён архив ровно того, что ушло на завод.

<Callout type="tip">
  Самая дешёвая проверка — **распечатать плату в масштабе 1:1** и положить на неё реальные компоненты.
  Ошибки в посадочных местах видно сразу.
</Callout>

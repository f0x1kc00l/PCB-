Здесь собраны только сочетания, которые сверены с официальными страницами горячих клавиш Altium Designer (ссылки внизу). Они действуют в актуальной версии; если что-то не срабатывает в твоей версии, проверь по встроенной справке.

<Callout type="tip">
  Две клавиши, которые стоит запомнить первыми. <Kbd keys="Shift+F1" /> во время любой команды показывает, какие клавиши
  сейчас доступны. <Kbd keys="F1" /> над объектом или командой открывает её документацию.
</Callout>

## Общие (во всех редакторах)

| Клавиши | Действие |
|---|---|
| <Kbd keys="Ctrl+S" /> | сохранить активный документ |
| <Kbd keys="Ctrl+O" /> | открыть документ |
| <Kbd keys="Ctrl+F4" /> | закрыть активный документ |
| <Kbd keys="Ctrl+P" /> | печать (где поддерживается) |
| <Kbd keys="Ctrl+Tab" /> / <Kbd keys="Shift+Ctrl+Tab" /> | следующий / предыдущий открытый документ |
| <Kbd keys="Alt+Left" /> / <Kbd keys="Alt+Right" /> | назад / вперёд по недавно открытым документам |
| <Kbd keys="F4" /> | показать или скрыть все плавающие панели |
| <Kbd keys="Shift+F4" /> | расположить открытые документы плиткой |
| <Kbd keys="Shift+F5" /> | переключить фокус между последней панелью и документом |
| <Kbd keys="Shift+Ctrl+F3" /> / <Kbd keys="Shift+Ctrl+F4" /> | следующее / предыдущее сообщение в панели Messages с переходом к объекту |
| <Kbd keys="Alt+F4" /> | выйти из Altium Designer |

## Редактор схем и библиотеки символов

### Правка и выделение

| Клавиши | Действие |
|---|---|
| двойной клик | свойства объекта под курсором |
| <Kbd keys="F2" /> | редактировать текст прямо на месте |
| <Kbd keys="Ctrl+C" />, <Kbd keys="Ctrl+X" />, <Kbd keys="Ctrl+V" /> | копировать, вырезать, вставить |
| <Kbd keys="Shift+Ctrl+V" /> | «умная» вставка (Smart Paste) |
| <Kbd keys="Ctrl+R" /> | копировать и вставлять многократно («штамп») |
| <Kbd keys="Ctrl+Z" /> / <Kbd keys="Ctrl+Y" /> | отменить / повторить |
| <Kbd keys="Ctrl+A" /> | выделить всё на листе |
| <Kbd keys="Shift+F" /> | найти похожие объекты (Find Similar Objects) |
| <Kbd keys="Alt" /> + клик по цепи | выделить цепь и подсветить её на всех листах проекта |
| <Kbd keys="Shift+Ctrl+X" /> | режим перекрёстного выделения схема ↔ плата (Cross Select Mode) |
| <Kbd keys="Ctrl+F" /> / <Kbd keys="Ctrl+H" /> / <Kbd keys="F3" /> | найти текст / найти и заменить / следующее совпадение |

### Размещение и перемещение

| Клавиши | Действие |
|---|---|
| <Kbd keys="Ctrl+W" /> | режим рисования проводников (Wire) |
| <Kbd keys="Space" /> / <Kbd keys="Shift+Space" /> | повернуть на 90° против / по часовой стрелке |
| <Kbd keys="X" /> / <Kbd keys="Y" /> | отразить по оси X / Y (во время перемещения) |
| <Kbd keys="Tab" /> | пауза и правка свойств объекта в панели Properties во время размещения |
| <Kbd keys="Esc" /> или правый клик | выйти из текущего шага команды |
| стрелки / <Kbd keys="Shift" /> + стрелки | курсор на 1 / 10 шагов сетки |
| <Kbd keys="Ctrl" /> + стрелки | сдвинуть выделенное на 1 шаг сетки |
| <Kbd keys="G" /> / <Kbd keys="Shift+G" /> | следующий / предыдущий шаг сетки привязки |
| <Kbd keys="Shift+Ctrl+G" /> | показать или скрыть видимую сетку |
| <Kbd keys="Shift+E" /> | включить или выключить электрическую сетку курсора |
| <Kbd keys="Shift+Ctrl+D" /> | привязать выделенное к ближайшему узлу сетки |

### Вид и прочее

| Клавиши | Действие |
|---|---|
| <Kbd keys="PgUp" /> / <Kbd keys="PgDn" /> | приблизить / отдалить относительно курсора |
| <Kbd keys="Ctrl+PgDn" /> | показать весь лист |
| правая кнопка + перетаскивание | панорама |
| <Kbd keys="Home" /> | центрировать вид на курсоре |
| <Kbd keys="F11" /> | панель Properties |
| <Kbd keys="F12" /> | панель фильтра SCH Filter |
| <Kbd keys="Ctrl+M" /> | измерить расстояние между двумя точками |
| <Kbd keys="Ctrl+Q" /> | в диалогах и панелях — переключить единицы мм/mil |
| <Kbd keys="Ctrl" /> + двойной клик | перейти между связанными портами, входами листов и дочерними листами |
| <Kbd keys="F9" /> | запустить симуляцию (нужно расширение Mixed Simulation) |

## Редактор плат и библиотеки посадочных мест

### Вид

| Клавиши | Действие |
|---|---|
| <Kbd keys="1" /> / <Kbd keys="2" /> / <Kbd keys="3" /> | режимы Board Planning / 2D / 3D |
| <Kbd keys="Ctrl+F" /> | перевернуть плату (вид снизу) |
| <Kbd keys="Shift+S" /> | циклически переключать режимы показа одного слоя |
| <Kbd keys="L" /> | панель View Configuration, вкладка слоёв и цветов |
| <Kbd keys="Ctrl+D" /> | View Configuration, вкладка параметров вида |
| <Kbd keys="Shift+Z" /> | показать или скрыть 3D-модели |
| <Kbd keys="F5" /> | включить или выключить раскраску цепей (Net Color Override) |
| <Kbd keys="Ctrl+PgDn" /> | показать все объекты |
| `Numpad +` / `Numpad −` | следующий / предыдущий слой |
| `Numpad *` | следующий сигнальный слой |
| <Kbd keys="Q" /> | переключить единицы метрические / дюймовые |
| <Kbd keys="Ctrl+M" /> | измерить расстояние между двумя точками |
| <Kbd keys="Shift+V" /> | список нарушений правил под курсором (Board Insight) |
| <Kbd keys="Shift+X" /> | список компонентов и цепей под курсором (Board Insight) |

### Выделение, выравнивание, подсветка

| Клавиши | Действие |
|---|---|
| <Kbd keys="Ctrl+A" /> | выделить всё |
| <Kbd keys="Ctrl+H" /> | выделить всё, что соединено медью с объектом |
| <Kbd keys="Shift+F" /> | найти похожие объекты |
| <Kbd keys="Ctrl" /> + клик по цепи | подсветить цепь (клик в пустом месте — снять подсветку) |
| <Kbd keys="Shift+C" /> | снять активный фильтр |
| <Kbd keys="Shift+Ctrl+L" />, <Kbd keys="Shift+Ctrl+R" />, <Kbd keys="Shift+Ctrl+T" />, <Kbd keys="Shift+Ctrl+B" /> | выровнять по левому, правому, верхнему, нижнему краю |
| <Kbd keys="Shift+Ctrl+H" /> / <Kbd keys="Shift+Ctrl+V" /> | выровнять шаг по горизонтали / вертикали |
| <Kbd keys="Ctrl+G" /> | редактор сетки привязки под курсором |
| <Kbd keys="F11" /> | панель Properties |
| <Kbd keys="F12" /> / <Kbd keys="Shift+F12" /> | панели PCB Filter / PCB List |

### Трассировка

| Клавиши | Действие |
|---|---|
| <Kbd keys="Ctrl+W" /> | интерактивная трассировка (Interactive Routing) |
| <Kbd keys="Tab" /> | параметры трассировки в панели Properties (во время трассировки) |
| клик или <Kbd keys="Enter" /> | зафиксировать дорожку до курсора |
| <Kbd keys="Backspace" /> | откатить последний зафиксированный участок |
| <Kbd keys="Ctrl" /> + клик | автоматически довести дорожку до цели |
| <Kbd keys="Esc" /> | закончить текущую дорожку |
| <Kbd keys="Space" /> / <Kbd keys="Shift+Space" /> | варианты излома / режимы углов (45°, 90°, дуги) |
| <Kbd keys="Shift+W" /> / <Kbd keys="Shift+V" /> | выбрать ширину дорожки / размер переходного из избранного |
| <Kbd keys="Shift+R" /> | режим разрешения конфликтов (обход, расталкивание…) |
| `Numpad *` или `Numpad +` | перейти на следующий сигнальный слой с установкой переходного |
| <Kbd keys="2" /> | поставить переходное отверстие без смены слоя |
| <Kbd keys="Shift+G" /> | показать индикатор длины (при выравнивании длин) |
| <Kbd keys="Shift+A" /> | трассировать выделенные соединения инструментом ActiveRoute |
| <Kbd keys="Ctrl+Alt+G" /> | сгладить (gloss) выделенные дорожки |

### Перемещение компонентов

| Клавиши | Действие |
|---|---|
| <Kbd keys="Space" /> / <Kbd keys="Shift+Space" /> | повернуть |
| <Kbd keys="L" /> | перенести компонент на другую сторону платы (во время перемещения) |
| <Kbd keys="Ctrl" /> + стрелки | сдвинуть выделенное на 1 шаг сетки (<Kbd keys="Shift+Ctrl" /> — на 10) |
| <Kbd keys="R" /> | режим расталкивания соседних компонентов (Avoid / Push / Ignore) |
| <Kbd keys="N" /> | режим показа линий связей (Pad To Pad, Breaks, Hidden) |

## Меню-подсказки по одной клавише

В редакторах схем и плат одиночная буква открывает всплывающее подменю: <Kbd keys="A" /> — выравнивание (Align),
<Kbd keys="J" /> — переход (Jump), <Kbd keys="K" /> — панели (Panels), <Kbd keys="M" /> — перемещение (Move),
<Kbd keys="O" /> — настройки (Options), <Kbd keys="S" /> — выделение (Select), <Kbd keys="X" /> — снятие выделения,
<Kbd keys="Z" /> — масштаб (Zoom). В редакторе плат ещё <Kbd keys="G" /> — команды сетки и <Kbd keys="I" /> — размещение компонентов.

<Callout type="altium">
  Набор горячих клавиш можно менять под себя, но в курсе везде указаны клавиши по умолчанию. Если ты переназначил
  клавишу, а урок не сходится, — дело в этом.
</Callout>

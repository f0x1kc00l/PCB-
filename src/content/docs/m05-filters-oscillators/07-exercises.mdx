1. **Порядок** ([5.1](../01-active-filters/)). Сигнал до 3 кГц, помеха на 30 кГц должна ослабиться на 60 дБ. Баттерворт со срезом 4 кГц — какой порядок?
   <details><summary>Ответ</summary>30/4 = 7,5; нужно 7,5ⁿ ≥ 1000 → n ≥ 3,4 → n = 4 (≈ −70 дБ).</details>

2. **Саллен — Ки** ([5.2](../02-filter-circuits/)). Единичное усиление, Баттерворт, f₀ = 10 кГц, C2 = 1 нФ, C1 = 2 нФ. R?
   <details><summary>Ответ</summary>R = 1/(2π·10⁴·√(2·10⁻¹⁸)) = 1/(2π·10⁴·1,414·10⁻⁹) ≈ 11,3 кОм → 11 кОм.</details>

3. **Верхние частоты** ([5.2](../02-filter-circuits/)). Как из звена 5.2 сделать фильтр верхних частот с тем же f₀?
   <details><summary>Ответ</summary>Поменять местами резисторы и конденсаторы. В ФВЧ с единичным усилением при равных C добротность задаёт отношение резисторов: Q = ½·√(Rзем/Rос), где Rзем — резистор от входа «+» на землю, Rос — от средней точки к выходу ОУ. Для Q = 0,707 нужно Rзем = 2·Rос.</details>

4. **Релаксационный** ([5.3](../03-oscillators/)). R1 = 10 кОм, R2 = 30 кОм, R = 10 кОм, C = 100 нФ. Период?
   <details><summary>Ответ</summary>β = 0,25; T = 2·10⁻³·ln(1,25/0,75) ≈ 2·10⁻³·0,51 ≈ 1,02 мс → ≈ 980 Гц.</details>

5. **555** ([5.3](../03-oscillators/)). Нужен 1 Гц для мигалки, C = 10 мкФ, RA = 10 кОм. RB?
   <details><summary>Ответ</summary>RA + 2RB = 1,44/(1·10⁻⁵) = 144 кОм → RB = 67 → 68 кОм.</details>

6. **Кварц** ([5.3](../03-oscillators/)). CL = 20 пФ, Cпар ≈ 3 пФ. C1 = C2?
   <details><summary>Ответ</summary>2·(20 − 3) = 34 → 33 пФ.</details>

7. **LC** ([5.3](../03-oscillators/)). Генератор Колпитца с катушкой 1 мкГн на 10 МГц. Какая эквивалентная ёмкость контура?
   <details><summary>Ответ</summary>C = 1/((2π·10⁷)²·10⁻⁶) ≈ 253 пФ (последовательные C1, C2 контура с учётом ёмкостей транзистора).</details>

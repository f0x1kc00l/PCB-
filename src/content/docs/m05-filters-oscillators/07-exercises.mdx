1. **Порядок** ([5.1](../01-active-filters/)). Сигнал до 3 кГц, помеха на 30 кГц должна ослабиться на 60 дБ. Баттерворт со срезом 4 кГц — какой порядок?
   <Check a={[{ label: "Порядок n", value: "4", tol: 0 }]} hint={["Вдали от среза Баттерворт n-го порядка ослабляет в (f/fс)ⁿ раз.", "60 дБ — это 1000 раз."]} />
   <details><summary>Решение</summary>30/4 = 7,5; нужно 7,5ⁿ ≥ 1000 → n ≥ 3,4 → n = 4 (≈ −70 дБ).</details>

2. **Саллен — Ки** ([5.2](../02-filter-circuits/)). Единичное усиление, Баттерворт, f₀ = 10 кГц, C2 = 1 нФ, C1 = 2 нФ. R?
   <Check a={[{ label: "R", unit: "Ом", value: "11,3к", tol: 3 }]} hint="Для равных R: f₀ = 1/(2πR√(C1·C2))." />
   <details><summary>Решение</summary>R = 1/(2π·10⁴·√(2·10⁻¹⁸)) = 1/(2π·10⁴·1,414·10⁻⁹) ≈ 11,3 кОм → 11 кОм.</details>

3. **Верхние частоты** ([5.2](../02-filter-circuits/)). Как из звена 5.2 сделать фильтр верхних частот с тем же f₀?
   <Check choices={["Поменять местами R и C", "Поменять местами входы ОУ", "Добавить конденсатор на выход"]} correct={0} hint="В ФВЧ на землю и в обратную связь «смотрят» резисторы, а последовательно с сигналом стоят конденсаторы." />
   <details><summary>Решение</summary>Поменять местами резисторы и конденсаторы. В ФВЧ с единичным усилением при равных C добротность задаёт отношение резисторов: Q = ½·√(Rзем/Rос), где Rзем — резистор от входа «+» на землю, Rос — от средней точки к выходу ОУ. Для Q = 0,707 нужно Rзем = 2·Rос.</details>

4. **Релаксационный** ([5.3](../03-oscillators/)). R1 = 10 кОм, R2 = 30 кОм, R = 10 кОм, C = 100 нФ. Период?
   <Check a={[{ label: "Период T", unit: "с", value: "1,02м", tol: 4 }]} hint={["β = R1/(R1 + R2).", "T = 2RC·ln((1 + β)/(1 − β))."]} />
   <details><summary>Решение</summary>β = 0,25; T = 2·10⁻³·ln(1,25/0,75) ≈ 2·10⁻³·0,51 ≈ 1,02 мс → ≈ 980 Гц.</details>

5. **555** ([5.3](../03-oscillators/)). Нужен 1 Гц для мигалки, C = 10 мкФ, RA = 10 кОм. RB?
   <Check a={[{ label: "RB", unit: "Ом", value: "67к", tol: 3 }]} hint="f = 1,44/((RA + 2RB)·C)." />
   <details><summary>Решение</summary>RA + 2RB = 1,44/(1·10⁻⁵) = 144 кОм → RB = 67 → 68 кОм.</details>

6. **Кварц** ([5.3](../03-oscillators/)). CL = 20 пФ, Cпар ≈ 3 пФ. C1 = C2?
   <Check a={[{ label: "C1 = C2", unit: "Ф", value: "34п", tol: 4 }]} hint="CL = C1·C2/(C1 + C2) + Cпар; при C1 = C2 это C/2 + Cпар." />
   <details><summary>Решение</summary>2·(20 − 3) = 34 → 33 пФ.</details>

7. **LC** ([5.3](../03-oscillators/)). Генератор Колпитца с катушкой 1 мкГн на 10 МГц. Какая эквивалентная ёмкость контура?
   <Check a={[{ label: "C экв.", unit: "Ф", value: "253п" }]} hint="f = 1/(2π√(LC))." />
   <details><summary>Решение</summary>C = 1/((2π·10⁷)²·10⁻⁶) ≈ 253 пФ (последовательные C1, C2 контура с учётом ёмкостей транзистора).</details>

## Зачем нужен BOM

**BOM (Bill of Materials, перечень элементов)** — таблица всего, что нужно купить и поставить на плату. Gerber говорит, какой будет плата, а BOM — что на ней будет стоять. Ошибка в BOM бьёт по деньгам: закупили не тот корпус — компоненты не встанут, перепутали номинал — плата заработает «как-то не так».

Аналогия: BOM — это список покупок для рецепта. «Мука — 500 г» недостаточно, нужно «мука пшеничная высшего сорта, марка такая-то». Иначе в магазине купят не то.

## Какие колонки нужны

| Колонка | Зачем | Пример |
|---|---|---|
| **Designator** — позиционные обозначения | где на плате | R1, R4 |
| **Quantity** — количество | сколько купить | 2 |
| **Comment / Value** — номинал | что это | 470 Ом |
| **Description** — описание | человекочитаемо | Резистор 0805 1 % 0,125 Вт |
| **Footprint** — корпус | какой корпус | 0805 |
| **Manufacturer** — производитель | однозначность | Yageo |
| **Manufacturer Part Number (MPN)** | точный артикул | RC0805FR-07470RL |
| **Поставщик и его артикул** | где купить | по необходимости |

Главная колонка — **MPN**. С ним BOM однозначен: «резистор 10 кОм 0805» бывает тысячи видов, а MPN один.

<Callout type="tip">
  Компоненты, которые ставить **не нужно** (вариант без них), помечай явно: отдельной колонкой или параметром
  «не устанавливать» (в англоязычной практике DNP / DNF — do not populate / do not fit). Монтажник не должен гадать,
  почему на площадке ничего нет.
</Callout>

## ActiveBOM

В Altium «живой» BOM проекта — документ **ActiveBOM** (файл `.BomDoc`). Он берёт компоненты из схемы и показывает:

- список позиций в нескольких видах (**Flat view**, **Base view**, **Consolidated view**);
- для каждой позиции — производителей и поставщиков с ценами и наличием (данные приходят из облачных сервисов Altium, нужен интернет и вход в аккаунт);
- столбец статуса **BOM Status** — риск по компоненту (снят с производства, нет на складе…);
- проверки **BOM Checks** — например, позиции без MPN; режим реакции на каждое нарушение настраивается.

В проекте может быть только **один** BomDoc.

Как добавить: правый клик по проекту в панели **Projects** → <MenuPath path="Add New to Project » ActiveBOM" verify /> (или через меню **File » New**). Документ попадает в проект, его нужно сохранить.

<Callout type="altium">
  Номер позиции (**Line #**) в ActiveBOM задаётся кнопкой **Set Line #** и работает только в Base view. Когда BOM
  генерируется из ActiveBOM, этот номер доступен как колонка и в выгрузке. Удобно, чтобы позиции BOM совпадали с
  выносками на сборочном чертеже (урок 10.7).
</Callout>

## Выгрузка BOM: Report Manager

Сам BomDoc заводу не отправляют. Выгружают таблицу через **Report Manager**: <MenuPath path="Reports » Bill of Materials" /> (команда есть в редакторах схемы, платы и в ActiveBOM). Если в проекте есть ActiveBOM, данные берутся из него автоматически.

<Screenshot src="screenshots/m10-manufacturing/l04-report-manager.png" alt="диалог Bill of Materials (Report Manager): таблица и настройки экспорта" />

В диалоге:

1. На вкладке **Columns** (панель Properties справа) включи нужные колонки: Designator, Quantity, Comment, Description, Footprint, Manufacturer 1, Manufacturer Part Number 1.
2. На вкладке **General** выбери **File Format**: MS-Excel, CSV, PDF и другие. Для Excel-формата можно выбрать **Template** — шаблон оформления.
3. Опции **Add to Project** (добавить файл в проект) и **Open Exported** (сразу открыть).
4. Кнопка **Export**.

В Output Job тот же BOM добавляется как **Report Outputs → Bill of Materials** (урок [10.6](../06-output-job/)).

## BOM и ЕСКД

В отечественной документации аналог BOM — **перечень элементов** (ПЭ3) к схеме и **спецификация** к сборочному чертежу. Это документы со строго заданной формой и основной надписью. Altium из коробки делает BOM «западного» вида. Перечень по ЕСКД обычно оформляют по шаблону в Excel или сторонними средствами. Для заказа на зарубежном сервисе ЕСКД не нужен, для отечественного предприятия — почти всегда. [ПРОВЕРИТЬ: наличие готовых шаблонов ЕСКД для Report Manager]

## Практика

1. Добавь в проект мультивибратора ActiveBOM.
2. Найди позиции без MPN (они подсветятся проверками) и подбери для резисторов, конденсаторов, транзисторов и светодиодов реальные артикулы.
3. Выгрузи BOM в Excel и CSV с колонками из таблицы выше.
4. Посчитай по данным ActiveBOM стоимость компонентов на одну плату и на 10 плат.

## Что такое файл сверловки

Сверлильный станок с ЧПУ не умеет читать картинки. Ему нужна программа: «возьми сверло 0,8 мм — сверли в точках (12,5; 7,0), (15,0; 7,0)… — смени сверло на 1,0 мм…». Такую программу описывает формат **Excellon** (его ещё называют **NC Drill**). В нём хранятся таблица инструментов (диаметры) и координаты отверстий для каждого инструмента.

Аналогия: Gerber — это рисунок, а Excellon — маршрутный лист для сверловщика.

## Металлизированные и неметаллизированные

- **Металлизированные (PTH, plated through hole)** — стенки покрыты медью, отверстие соединяет слои. Это переходные отверстия (via) и отверстия под выводы.
- **Неметаллизированные (NPTH, non-plated)** — просто дырка в стеклотекстолите: крепёжные отверстия, направляющие под разъёмы.

Завод сверлит их на разных этапах: металлизированные — до осаждения меди, неметаллизированные — обычно после. Поэтому их удобно передавать **отдельными файлами**.

<Callout type="tip">
  В файле сверловки указан **диаметр сверла**, а в Altium ты задаёшь **готовый диаметр отверстия** (finished hole size).
  Металлизация «съедает» часть диаметра, и завод сам добавляет припуск. Не увеличивай отверстия «на металлизацию»
  самостоятельно, если завод явно не попросил.
</Callout>

## Настройка в Altium

В редакторе платы: <MenuPath path="File » Fabrication Outputs » NC Drill Files" /> → диалог **NC Drill Setup**.

<Screenshot src="screenshots/m10-manufacturing/l03-nc-drill-setup.png" alt="диалог NC Drill Setup" />

| Группа | Параметр | Что выбрать |
|---|---|---|
| **NC Drill Format** | Units | те же единицы, что у Gerber |
| | Format | наибольшая точность, например 2:5 для дюймов (для мм — 4:4); как у Gerber |
| **Leading/Trailing Zeroes** | Keep / Suppress… | как у Gerber; чаще всего оставляют значение по умолчанию |
| **Coordinate Positions** | Reference to absolute / relative origin | **та же точка отсчёта, что у Gerber** |
| **Other** | Generate separate NC Drill files for plated & non-plated holes | **включить** |
| | Use drilled slot command (G85) | см. ниже про пазы |
| | Generate EIA Binary Drill File (.DRL) | обычно не нужен, заводы берут текстовый .TXT |

Altium создаст текстовые файлы сверловки (`.TXT`, при разделении — `-Plated.TXT` и `-NonPlated.TXT`), отчёт `.DRR` (таблица инструментов — полезно глянуть) и отчёт по парам слоёв `.LDP`.

<Callout type="altium">
  Сверловка из Altium — текстовый Excellon. При импорте в редактор CAM самого Altium поддерживаются только текстовые
  (ASCII) файлы сверловки, двоичный .DRL туда не загрузить. Это ещё одна причина не путать .TXT и .DRL.
</Callout>

## Пазы (slots)

Овальное отверстие под широкий вывод разъёма или кнопки — это **паз**. Передать его можно двумя способами:

1. **Командой сверловки G85** («drilled slot»): паз описан как отрезок, который станок проходит сверлом. В Altium это опция **Use drilled slot command (G85)**.
2. **Фрезеровкой по контуру** на механическом слое, как вырез.

Заводы по-разному относятся к этим вариантам. Посмотри требования своего производителя и **явно напиши в комментарии к заказу**, что на плате есть пазы.

## Минимальные размеры

Диаметр отверстий и ширина пояска вокруг них (annular ring) ограничены технологией завода. Пример из публичных возможностей сервисов прототипов для стандартных двухслойных плат: минимальное отверстие около 0,15–0,2 мм, рекомендуемый поясок от 0,15–0,25 мм, минимальное неметаллизированное отверстие 0,5 мм у одного из них. Цифры меняются: **окончательные значения бери из технологических норм своего производителя** и закладывай запас. Для первой платы спокойно используй переходные отверстия 0,3–0,4 мм.

## Практика

1. Выгрузи NC Drill для мультивибратора с теми же единицами и точкой отсчёта, что у Gerber из урока 10.2.
2. Включи разделение металлизированных и неметаллизированных отверстий.
3. Открой отчёт `.DRR`: сколько инструментов (диаметров) получилось? Нет ли «случайных» диаметров, отличающихся на сотые доли миллиметра? Если есть — приведи их к одному.
4. Загрузи Gerber и сверловку в просмотрщик и убедись, что отверстия попадают в центры площадок.

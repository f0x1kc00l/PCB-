## Шаблон ТЗ

Скопируй и заполни. Если какую-то строку заполнить не можешь — это вопрос, который нужно решить **до** схемы.

| Раздел | Что написать | Пример |
|---|---|---|
| Назначение | одна фраза: что делает устройство и для кого | «Датчик температуры и влажности для теплицы, раз в минуту отправляет данные по Wi-Fi» |
| Входы и выходы | что подключается и как: разъёмы, сигналы, уровни | USB-C (питание и прошивка), разъём датчика I²C |
| Питание | источник, диапазон напряжений, потребление | USB 5 В или Li-ion 3,0–4,2 В; в сне < 50 мкА |
| Условия работы | температура, влажность, вибрация, корпус | от −10 до +50 °C, корпус 60×40×20 мм |
| Механика | размер платы, крепёж, положение разъёмов | 50×30 мм, 2 отверстия M2, USB на короткой кромке |
| Ключевые компоненты | основные микросхемы и почему они | ESP32-C3: Wi-Fi, низкое потребление в сне |
| Проверка | как ты убедишься, что всё работает | измерить ток сна, проверить связь на расстоянии 20 м |
| Ограничения | бюджет, сроки, производитель, ручная или заводская сборка | до N единиц валюты за 5 плат, сборка своими руками |

<Callout type="tip">
  Хорошая первая самостоятельная плата делает **одну вещь хорошо**. «Метеостанция с дисплеем, батареей, солнечной
  панелью и LoRa» — это пять проектов. Начни с ядра и оставь на плате контактные площадки «на вырост».
</Callout>

## Идеи для первого своего проекта

По нарастающей сложности:

1. **Плата светодиодного индикатора** с транзисторными ключами и кнопками (модуль 3, урок 3.5).
2. **Таймер на NE555** с регулируемой частотой — продолжение темы генераторов (Хоровиц, §5.14).
3. **Зарядное устройство Li-ion** на специализированной микросхеме заряда с защитой аккумулятора — тепло, токи, полярность.
4. **Драйвер двигателя** на H-мосте — силовые дорожки, полигоны, развязка.
5. **Плата датчиков** (температура, влажность, освещённость) на I²C с микроконтроллером.
6. **Беспроводной модуль** на ESP32 с готовым модулем-антенной — правила зоны антенны из даташита модуля.
7. **Адаптер-переходник** для своего хобби: шилд для Arduino, плата-разветвитель питания, преобразователь уровней 5 В ↔ 3,3 В.
8. **Плата под свой корпус** — от механики к электронике: сначала размеры и отверстия, потом схема.

## Чек-лист ревью схемы

- [ ] ТЗ заполнено, каждое требование проверяемо.
- [ ] Для каждой микросхемы прочитан даташит: питание, типовая схема включения, требования к конденсаторам, abs max.
- [ ] Нет выводов «в воздухе»: неиспользуемые входы подтянуты или подключены по рекомендации даташита.
- [ ] Посчитаны: мощность каждого резистора и стабилизатора, токи светодиодов, делители, нагрев.
- [ ] Защита: переполюсовка, ESD на внешних разъёмах, предохранитель по питанию.
- [ ] Уровни сигналов между микросхемами совместимы (3,3 В ↔ 5 В).
- [ ] Компиляция (Validate) без ошибок, все предупреждения разобраны.
- [ ] Схема читаема: узлы подписаны, сигналы названы, есть примечания с расчётами.

## Чек-лист ревью платы

- [ ] Посадочные места сверены с даташитами, печать 1:1 проверена.
- [ ] Разъёмы и крепёж на своих местах, 3D-проверка с корпусом.
- [ ] Силовые дорожки посчитаны по току (урок [5.4](../../m05-pcb-design/04-trace-width/)), тепловые полигоны есть где нужно.
- [ ] Развязка у каждого вывода питания, сплошная земля без островов.
- [ ] Критичные цепи (кварц, USB, аналоговые, силовые) разведены по правилам.
- [ ] Шелкография: обозначения, полярность, первый вывод, подписи разъёмов, название и версия.
- [ ] Контрольные точки для отладки.
- [ ] DRC — 0 нарушений, правила соответствуют нормам производителя.

## Критерии «готово к заказу»

Проект можно отправлять на завод, когда выполнены **все** пункты:

1. Оба чек-листа закрыты.
2. Выходные файлы сгенерированы из актуальной версии проекта и проверены в просмотрщике Gerber (урок [10.8](../../m10-manufacturing/08-gerber-viewer/)).
3. Предпросмотр на сайте производителя совпадает с твоим.
4. BOM полный, все позиции есть в наличии у поставщика, есть замены для дефицитных.
5. Есть план запуска: что и в каком порядке включать, какие напряжения мерить.
6. Версия проекта зафиксирована (архив или Project Releaser), номер версии — на шелкографии.

<Callout type="warning">
  Самая дорогая ошибка самостоятельного проекта — «ну, почти всё проверил, закажу, а там посмотрим». Плата приходит
  через одну–три недели, и каждая итерация стоит денег и времени. Час ревью экономит неделю.
</Callout>

Самая творческая часть: превращаем «резинки» связей в медные дорожки. На учебной плате деталей всего девять, но приёмы те же, что и на плате с сотней компонентов: сначала продуманное размещение, потом трассировка.

<TutorialFlow current={6} />

## Часть 1. Размещение

1. Приблизь вид так, чтобы были видны и плата, и детали рядом с ней.
2. Проверь в строке состояния, что **Snap Grid** = 1 мм. Если нет — <MenuPath path="View » Grids » Set Global Snap Grid" />.
3. Перетаскивай детали на плату: зажми контур детали и тащи. Курсор прыгнет к центру ближайшей площадки — так деталь ложится точно на сетку.
4. Во время перетаскивания <Kbd keys="Space" /> поворачивает деталь на 90° против часовой стрелки.
5. Следи за линиями связей: они перерисовываются на ходу. Разворачивай детали так, чтобы линий было меньше и они не перекрещивались.
6. Разъём **P1** поставь у **левого края** платы.
7. Обозначения (designators) двигай так же, перетаскиванием, и поворачивай <Kbd keys="Space" />. Или выдели их и примени **Autoposition** в панели Properties.
8. Сохрани плату.

<Screenshot src="screenshots/m07-multivibrator/l06-placement.png" alt="размещённые компоненты мультивибратора на плате 30×30 мм с линиями связей" />

**Почему так.** Хорошее размещение — 80 % хорошей трассировки (урок [5.2](../../m05-pcb-design/02-placement/)). Правила для нашей платы:

- **разъём — у края**, иначе провод питания будет мешать и цепляться за детали;
- **повтори симметрию схемы**: два плеча мультивибратора одинаковы, пусть и на плате они будут зеркальными;
- **связанные детали — рядом**: R1 и C1 около базы Q1, R3 около коллектора Q1;
- **минимум пересечений линий связей**: каждое пересечение на двухслойке — это переход на другой слой или обход.

## Часть 2. Настройка трассировщика

1. **Preferences** → **PCB Editor** → **Interactive Routing**.
2. **Routing Conflict Resolution** → **Current Mode** = **Walkaround Obstacles** (обход препятствий).
3. **Interactive Routing Width Sources**: **Track Width Mode** = **Rule Preferred**, **Via Size Mode** = **Rule Preferred**.
4. **OK**.
5. Сетка для трассировки — `0.25` мм: <MenuPath path="View » Grids » Set Global Snap Grid" />.
6. Сделай активным слой **Top Layer** — щелчком по его ярлыку внизу окна.

**Почему так.** *Rule Preferred* означает: трассировщик берёт ширину из Constraint Manager (урок 7.4). Сигнальные дорожки будут 0,25 мм, цепи класса Power — 0,5 мм, и думать об этом вручную не надо. *Walkaround* обходит чужие объекты, соблюдая зазор 0,25 мм, а не проводит дорожку сквозь них.

## Часть 3. Трассировка

1. <MenuPath path="Route » Interactive Routing" /> или <Kbd keys="Ctrl+W" />. Курсор станет крестиком.
2. Щёлкни по площадке — начало дорожки. Руководство начинает с нижней площадки P1.
3. Веди дорожку, щелчками фиксируя сегменты, и закончи на площадке нужной цепи. Altium подсвечивает площадки той же цепи, куда можно прийти.
4. Повтори для остальных связей. <Kbd keys="Ctrl" /> + щелчок пытается достроить соединение автоматически.
5. Сохрани плату.

### Клавиши во время трассировки

| Клавиша | Действие |
|---|---|
| <Kbd keys="Shift+F1" /> | список всех клавиш трассировки |
| <Kbd keys="Tab" /> | панель Properties с настройками трассировки (ширина, слой) |
| <Kbd keys="Space" /> | сменить направление текущего угла |
| <Kbd keys="Shift+Space" /> | перебрать режимы углов (45°, 90°, дуги…) |
| <Kbd keys="Shift+R" /> | перебрать режимы разрешения конфликтов (обход, расталкивание…) |
| <Kbd keys="3" /> | перебрать ширину: минимум / предпочтительная / максимум из правила / своя |
| <Kbd keys="*" /> на цифровой клавиатуре или <Kbd keys="Ctrl+Shift" /> + колесо | перейти на другой слой; переходное отверстие ставится по правилу |
| <Kbd keys="Backspace" /> | убрать последний сегмент |
| <Kbd keys="Ctrl" /> + щелчок | автоматически достроить соединение (не сработает, если мешают препятствия) |
| правый клик | бросить текущую дорожку и остаться в режиме; второй правый клик — выход |

Чтобы поправить готовую дорожку, зажми её сегмент и тащи: соседние сегменты подстроятся.

<Screenshot src="screenshots/m07-multivibrator/l06-routed.png" alt="полностью разведённая плата мультивибратора: дорожки питания шире сигнальных" />

<Callout type="tip">
  Порядок трассировки: сначала **питание и земля** (широкие и важные), потом **сигналы**. На нашей плате большинство
  связей легко развести на одном верхнем слое. Где не получается — уходи на нижний слой через переходное отверстие (<Kbd keys="*" />)
  и возвращайся. Углы делай под 45°, без «пил» и петель (урок [5.3](../../m05-pcb-design/03-routing/)).
</Callout>

**Почему так.** Руководство разводит плату вручную, интерактивным трассировщиком. На маленькой плате руками получается быстрее и аккуратнее, а главное, ты понимаешь каждую дорожку. Сплошной полигон земли руководство на этой плате не делает: при токах в десятки миллиампер и частоте ~330 Гц это не нужно. Как и зачем заливать землю на более серьёзных платах — урок [5.6](../../m05-pcb-design/06-pours-ground/).

## Часть 4. Смотрим в 3D

1. <MenuPath path="View » 3D Layout Mode" /> (<Kbd keys="3" />).
2. Зум — колесо с <Kbd keys="Ctrl" />, панорама — правой кнопкой.
3. Вращение — <Kbd keys="Shift" /> + правая кнопка мыши. При нажатом Shift у курсора появляется сфера-указатель направления.
4. Вернуться в 2D — <MenuPath path="View » 2D Layout Mode" /> (<Kbd keys="2" />).

<Screenshot src="screenshots/m07-multivibrator/l06-3d.png" alt="3D-вид платы мультивибратора с транзисторами, резисторами, конденсаторами и разъёмом" />

**Почему так.** 3D-вид ловит то, что в 2D не видно: деталь, вылезающую за край платы, разъём, к которому не подлезть с проводом, неудачно лёгшую шелкографию.

<Callout type="altium">
  Горячие клавиши трассировки — из руководства. В разных версиях набор режимов углов и разрешения конфликтов немного
  отличается. Если клавиша ведёт себя иначе, нажми <Kbd keys="Shift+F1" /> прямо во время трассировки — Altium покажет
  актуальный список для твоей версии.
</Callout>

  2. Попробуй развести всё на **одном** слое (Top Layer). Если не выходит, используй минимум переходов на Bottom Layer.

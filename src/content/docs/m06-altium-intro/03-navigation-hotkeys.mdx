Опытный конструктор почти не лезет в меню: руки на мыши и клавиатуре, и за час он делает то, на что новичок тратит день. Учить всё сразу не нужно. Начни с навигации — без неё на плате не развернёшься — и с десятка самых частых команд.

## Два вида горячих клавиш

В Altium есть клавиши двух типов:

- **Комбинации** — нажимаются одновременно: <Kbd keys="Ctrl+S" /> сохранить, <Kbd keys="Ctrl+Z" /> отменить.
- **Последовательности (accelerator keys)** — нажимаются **по очереди**, как путь по меню: <Kbd keys="P, W" /> — меню **Place**, пункт **Wire**. Если помнишь, где команда в меню, ты почти наверняка знаешь её последовательность: это первые буквы пунктов.

Аналогия — быстрый набор номера в телефоне: вместо того чтобы листать контакты, набираешь пару цифр.

## Навигация: одинаково в схеме и на плате

| Действие | Клавиши и мышь |
|---|---|
| Приблизить / отдалить относительно курсора | <Kbd keys="PgUp" /> / <Kbd keys="PgDn" />, или <Kbd keys="Ctrl" /> + колесо мыши |
| Панорама (сдвинуть вид) | зажать **правую** кнопку мыши и тащить |
| Прокрутка вверх-вниз / влево-вправо | колесо мыши / <Kbd keys="Shift" /> + колесо |
| Показать все объекты документа | <Kbd keys="Ctrl+PgDn" /> |
| Вписать документ (весь лист) | <Kbd keys="V, D" /> |
| Вписать все объекты (схема) / всю плату (PCB) | <Kbd keys="V, F" /> |

<Callout type="tip">
  Короткий щелчок правой кнопкой и правый щелчок с перетаскиванием — разные вещи. Перетаскивание сдвигает вид,
  короткий щелчок во время команды отменяет текущий шаг, как <Kbd keys="Esc" />. Сначала это путает, через день
  становится привычкой.
</Callout>

## Самые нужные клавиши в редакторе схем

| Клавиши | Что делают |
|---|---|
| <Kbd keys="P, P" /> | открыть панель Components, чтобы разместить компонент |
| <Kbd keys="P, W" /> | начать рисовать проводник (Wire) |
| <Kbd keys="Space" /> / <Kbd keys="Shift+Space" /> | повернуть размещаемый или перемещаемый объект на 90° против / по часовой стрелке |
| <Kbd keys="X" /> / <Kbd keys="Y" /> | зеркально отразить объект по горизонтали / вертикали во время перемещения |
| <Kbd keys="Tab" /> | во время размещения — пауза и панель Properties, чтобы сразу задать свойства |
| <Kbd keys="Esc" /> | выйти из текущего шага или команды |
| <Kbd keys="G" /> / <Kbd keys="Shift+G" /> | перебрать заданные шаги сетки привязки вперёд / назад |
| <Kbd keys="Alt" /> + щелчок по цепи | подсветить цепь на всех листах проекта |
| <Kbd keys="Shift+C" /> | снять текущую подсветку (фильтр) |
| <Kbd keys="Ctrl+M" /> | измерить расстояние между двумя точками |
| <Kbd keys="T, A" /> | открыть диалог аннотации (нумерация позиционных обозначений) |
| <Kbd keys="T, P" /> | открыть настройки редактора схем |

Единицы в редакторе схем переключаются командой <MenuPath path="View » Toggle Units" /> (последовательность <Kbd keys="V, U" />).

## Самые нужные клавиши в редакторе платы

| Клавиши | Что делают |
|---|---|
| <Kbd keys="Q" /> | переключить единицы документа: миллиметры ↔ милы (mil, 1/1000 дюйма) |
| <Kbd keys="P, T" /> | интерактивная трассировка (рисовать дорожку) |
| <Kbd keys="Space" /> / <Kbd keys="Shift+Space" /> | повернуть размещаемый или перемещаемый объект |
| <Kbd keys="Tab" /> | во время размещения или трассировки — панель Properties с параметрами |
| <Kbd keys="Shift+R" /> | перебрать режимы разрешения конфликтов при трассировке |
| <kbd>Num +</kbd> / <kbd>Num −</kbd> на цифровом блоке | следующий / предыдущий слой |
| <kbd>Num *</kbd> на цифровом блоке | следующий сигнальный слой |
| <Kbd keys="Shift+S" /> | режимы просмотра одного слоя |
| <Kbd keys="L" /> | панель View Configuration, вкладка слоёв и цветов |
| <Kbd keys="2" /> / <Kbd keys="3" /> | двумерный / трёхмерный вид |
| <Kbd keys="G" /> / <Kbd keys="Ctrl+G" /> | меню сетки привязки / редактор сетки под курсором |
| <Kbd keys="Ctrl" /> + щелчок по цепи | подсветить всю разведённую цепь |
| <Kbd keys="Shift+C" /> | снять подсветку (фильтр) |
| <Kbd keys="Ctrl+M" /> | измерить расстояние |
| <Kbd keys="D, R" /> | редактор правил проектирования (Rules and Constraints Editor) |
| <Kbd keys="T, D, R" /> | пакетная проверка правил (DRC) |
| <Kbd keys="T, P" /> | настройки редактора платы |

<Callout type="altium">
  В 3D-виде (<Kbd keys="3" />) плату вращают, зажав <Kbd keys="Shift" /> и перетаскивая правой кнопкой мыши.
  Клавиша <Kbd keys="0" /> ставит вид строго сверху без поворота. Это удобно, чтобы проверить, как встанут
  компоненты и разъёмы, — подробно в модуле 8 (3D-модели).
</Callout>

## Общие клавиши

| Клавиши | Что делают |
|---|---|
| <Kbd keys="Ctrl+S" /> | сохранить активный документ |
| <Kbd keys="Ctrl+O" /> | открыть файл |
| <Kbd keys="Ctrl+Z" /> / <Kbd keys="Ctrl+Y" /> | отменить / повторить |
| <Kbd keys="Ctrl+Tab" /> | следующий открытый документ |
| <Kbd keys="Ctrl+F4" /> | закрыть активный документ |
| <Kbd keys="F1" /> | справка по объекту, панели или команде под курсором |
| <Kbd keys="Shift+F1" /> | **во время команды** — список клавиш, доступных именно на этом шаге |

<Callout type="tip">
  <Kbd keys="Shift+F1" /> — главная шпаргалка. Начал трассировку, забыл, как поменять ширину или сменить слой, —
  нажми её прямо посреди команды. Меню закрывается по <Kbd keys="Esc" />, команда при этом не прерывается.
</Callout>

## Свои горячие клавиши

Любой команде меню можно назначить свою клавишу: зажми <Kbd keys="Ctrl" /> и щёлкни по пункту меню или кнопке
панели инструментов. Откроется диалог **Edit Command**, в нём есть поля для основной (**Primary**) и
альтернативной (**Alternative**) клавиши.

Пример из базы знаний Altium: в редакторе платы <Kbd keys="Q" /> переключает единицы, а в редакторе схем по
умолчанию нет. Можно назначить <Kbd keys="Q" /> команде **Toggle Units** и в схеме — так рука не будет путаться.

## Практика в Altium

Открой любой пример с платой (как найти — урок [6.6](../06-first-look/)) или свою плату.

1. На плате нажми <Kbd keys="V, F" /> — плата впишется в окно.
2. Приблизь угол платы колесом с <Kbd keys="Ctrl" />, сдвинь вид правой кнопкой мыши, вернись по <Kbd keys="V, F" />.
3. Нажми <Kbd keys="Q" /> несколько раз и следи за координатами в строке состояния: mm ↔ mil.
4. Переключай слои клавишами <kbd>Num +</kbd> и <kbd>Num −</kbd> на цифровом блоке и смотри на вкладки слоёв внизу рабочей области.
5. Включи 3D (<Kbd keys="3" />), повращай плату с зажатым <Kbd keys="Shift" />, вернись в 2D (<Kbd keys="2" />).
6. Запусти <Kbd keys="P, T" />, нажми <Kbd keys="Shift+F1" /> и посмотри, какие клавиши доступны при трассировке. Выйди по <Kbd keys="Esc" />.

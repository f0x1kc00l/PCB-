**Цель:** увидеть своими глазами то, что считали в уроке [1.5](../../m01-basics/05-divider-thevenin/): делитель выдаёт U·R2/(R1+R2) только без нагрузки, а под нагрузкой проседает ровно так, как предсказывает эквивалентный генератор.

## Что нужно

- Arduino Uno (питание 5 В) **или** любая плата ESP32 (3,3 В);
- макетная плата и провода;
- резисторы: 2 × 10 кОм, 10 кОм, 1 кОм (нагрузки);
- мультиметр.

<Callout type="warning">
  У ESP32 вход АЦП выдерживает только до 3,3 В. Делитель питай от вывода **3V3**, а не от 5 В. У Arduino Uno — от **5V**.
</Callout>

## Сборка

1. R1 = 10 кОм — от питания (5V или 3V3) к средней точке.
2. R2 = 10 кОм — от средней точки на GND.
3. Среднюю точку — на вход АЦП: **A0** у Uno, **GPIO34** у ESP32 (у ESP32-S3 — GPIO4). Это вход ADC1, он работает и при включённом Wi-Fi.

## Предскажи

Сначала посчитай на живой схеме: выставь своё питание и номиналы, включай нагрузку 10 кОм и 1 кОм.

## Код

Скетч печатает напряжение раз в полсекунды, усредняя 32 отсчёта АЦП. Открой «Монитор порта» на 115200.

```cpp
// Лаба 1: делитель под нагрузкой. Работает на Arduino Uno и на ESP32.
#if defined(ARDUINO_ARCH_ESP32)
const int ADC_PIN = 34;              // ESP32: GPIO34 (ADC1). Для ESP32-S3 поставь 4.
float readVolts() {
  // встроенная калибровка АЦП по eFuse — точнее, чем analogRead()
  return analogReadMilliVolts(ADC_PIN) / 1000.0;
}
#else
const int ADC_PIN = A0;              // Arduino Uno
const float VREF = 5.0;              // опорное = питание; измерь мультиметром и впиши точнее
float readVolts() {
  return analogRead(ADC_PIN) * VREF / 1023.0;
}
#endif

void setup() {
  Serial.begin(115200);
  delay(500);
  Serial.println("U, В (среднее 32 отсчётов)");
}

void loop() {
  float sum = 0;
  for (int i = 0; i < 32; i++) {
    sum += readVolts();
    delay(2);
  }
  Serial.println(sum / 32.0, 3);
  delay(500);
}
```

## Разбор

- Без нагрузки выход — половина питания. С нагрузкой 10 кОм — треть (эквивалент: Uпит/2 и 5 кОм, нагрузка 10 кОм → 2/3 от Uпит/2).
- С нагрузкой 1 кОм выход падает примерно в 6 раз: Rэ = 5 кОм уже много больше нагрузки. Вывод из урока: **делитель — не источник питания**.
- Мультиметр и АЦП тоже нагрузка. Входное сопротивление мультиметра — около 10 МОм, им можно пренебречь. А вот АЦП Uno при источнике сопротивлением больше 10 кОм начинает врать: его конденсатор выборки не успевает зарядиться. Поэтому для АЦП делители делают низкоомными или ставят конденсатор 100 нФ от входа на землю.

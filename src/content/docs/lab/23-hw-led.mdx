**Цель:** убедиться, что прямое напряжение светодиода почти не зависит от тока (урок [1.17](../../m01-basics/17-leds/)), и проверить расчёт токоограничивающего резистора.

## Что нужно

- Arduino Uno (5 В) или ESP32 (3,3 В);
- красный светодиод (у ESP32 с 3,3 В синий и белый почти не светят — проверь на живой схеме ниже почему);
- резисторы 2,2 кОм, 1 кОм, 470 Ом, 220 Ом;
- мультиметр.

## Сборка

Питание (5V у Uno, 3V3 у ESP32) → резистор → анод светодиода (длинная ножка); катод — на GND. Анод — на вход АЦП (**A0** у Uno, **GPIO34** у ESP32).

## Код

Впиши в скетч номинал стоящего резистора — он сам посчитает ток.

```cpp
// Лаба 3: прямое напряжение и ток светодиода. Arduino Uno и ESP32.
const float R = 1000.0;              // ← номинал резистора, Ом

#if defined(ARDUINO_ARCH_ESP32)
const int ADC_PIN = 34;              // ESP32-S3: 4 (ADC1)
const float UPIT = 3.3;              // измерь мультиметром на выводе 3V3 и впиши
float readVolts() { return analogReadMilliVolts(ADC_PIN) / 1000.0; }
#else
const int ADC_PIN = A0;
const float UPIT = 5.0;              // измерь мультиметром на выводе 5V и впиши
float readVolts() { return analogRead(ADC_PIN) * UPIT / 1023.0; }
#endif

void setup() {
  Serial.begin(115200);
}

void loop() {
  float uf = 0;
  for (int i = 0; i < 32; i++) uf += readVolts();
  uf /= 32.0;
  float i_mA = (UPIT - uf) / R * 1000.0;
  Serial.print("Uпр = ");
  Serial.print(uf, 3);
  Serial.print(" В, I = ");
  Serial.print(i_mA, 2);
  Serial.println(" мА");
  delay(700);
}
```

## Измерь и заполни

| R | Uпр, В | I, мА | Яркость (на глаз) |
|---|---|---|---|
| 2,2 кОм | | | |
| 1 кОм | | | |
| 470 Ом | | | |
| 220 Ом | | | |

## Разбор

- Ток меняется в 10 раз, а Uпр — на десятые доли вольта. Это и есть экспоненциальная ВАХ диода: поэтому ток задают резистором, а не напряжением.
- Яркость растёт с током почти линейно, но уже от 2–5 мА индикатор светит хорошо — 20 мА на плате обычно избыточно.

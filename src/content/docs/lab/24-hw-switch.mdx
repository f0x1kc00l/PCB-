**Цель:** проверить правило из урока [2.2](../../m02-transistors/02-transistor-switch/): ключ хорошо замкнут (Uкэ ≈ 0,1 В), только когда β·Iб с запасом больше тока нагрузки.

## Что нужно

- Arduino Uno или ESP32;
- NPN-транзистор BC547, 2N2222 или 2N3904;
- нагрузка: светодиод + резистор 220 Ом от 5 В (ток ≈ 13 мА);
- резисторы в базу: 1 кОм, 10 кОм, 100 кОм.

<Callout type="warning">
  Нагрузку питай от **5V** (у ESP32 — вывод 5V/VIN при питании от USB), а коллектор на вход АЦП ESP32 подавай через делитель
  10 кОм / 10 кОм: в выключенном состоянии на коллекторе почти 5 В, а АЦП ESP32 выдерживает только 3,3 В. У Uno делитель не нужен.
</Callout>

## Сборка

1. 5V → резистор 220 Ом → светодиод (анод к резистору) → коллектор транзистора.
2. Эмиттер — на GND.
3. Вывод **D7** (Uno) / **GPIO25** (ESP32) / **GPIO5** (ESP32-S3) → Rб → база.
4. Коллектор → вход АЦП (**A0** / **GPIO34**, у ESP32 — через делитель 2:1).

## Код

```cpp
// Лаба 4: транзисторный ключ — измеряем Uкэ во включённом и выключенном состоянии.
#if defined(ARDUINO_ARCH_ESP32)
const int CTRL_PIN = 25;             // ESP32-S3: GPIO25 нет — возьми 5
const int ADC_PIN = 34;              // ESP32-S3: 4 (ADC1)
const float DIV = 2.0;               // делитель 10к/10к на входе АЦП
float readVolts() { return analogReadMilliVolts(ADC_PIN) / 1000.0 * DIV; }
#else
const int CTRL_PIN = 7;
const int ADC_PIN = A0;
float readVolts() { return analogRead(ADC_PIN) * 5.0 / 1023.0; }
#endif

float avg() {
  float s = 0;
  for (int i = 0; i < 32; i++) s += readVolts();
  return s / 32.0;
}

void setup() {
  Serial.begin(115200);
  pinMode(CTRL_PIN, OUTPUT);
}

void loop() {
  digitalWrite(CTRL_PIN, HIGH);
  delay(300);
  float on = avg();
  digitalWrite(CTRL_PIN, LOW);
  delay(300);
  float off = avg();
  Serial.print("Uкэ вкл = ");
  Serial.print(on, 3);
  Serial.print(" В   Uкэ выкл = ");
  Serial.print(off, 2);
  Serial.println(" В");
  delay(1500);
}
```

## Измерь и заполни

| Rб | Uкэ вкл., В | Режим | Светодиод |
|---|---|---|---|
| 1 кОм | | | |
| 10 кОм | | | |
| 100 кОм | | | |

Предскажи на живой схеме: выставь Uвх = 5 В (или 3,3 В), Rк ≈ 220 Ом + светодиод (возьми 330 Ом как эквивалент), β ≈ 200.

## Разбор

- С 1 кОм ток базы ≈ 4 мА — в десятки раз больше нужного: глубокое насыщение, Uкэ ≈ 0,05–0,15 В.
- С 100 кОм ток базы ≈ 40 мкА, β·Iб ≈ 4–10 мА — меньше тока нагрузки: транзистор в активном режиме, на нём вольты, светодиод тусклый, транзистор греется.
- Вывод: Rб считают так, чтобы β.мин·Iб было в 5–10 раз больше тока нагрузки.

**Цель:** получить настоящую экспоненту из урока [1.11](../../m01-basics/11-rc-circuits/) и проверить, что за время τ = RC конденсатор заряжается на 63 %.

## Что нужно

- Arduino Uno или ESP32;
- резистор 10 кОм, электролитический конденсатор 100 мкФ (τ = 10 кОм · 100 мкФ = 1 с);
- макетная плата, провода.

## Сборка

1. Цифровой вывод **D7** (Uno), **GPIO25** (ESP32) или **GPIO5** (ESP32-S3) → резистор 10 кОм → «+» конденсатора.
2. «−» конденсатора — на GND. **Полярность важна:** полоса на корпусе электролита — минус.
3. «+» конденсатора — на вход АЦП: **A0** (Uno), **GPIO34** (ESP32) или **GPIO4** (ESP32-S3).

<Callout type="tip">
  Выход микроконтроллера — почти идеальный источник напряжения: его сопротивление — десятки ом, а у нас 10 кОм. Поэтому
  τ определяется только R и C. Допуск электролита — часто ±20 %, так что τ от 0,8 до 1,2 с — норма.
</Callout>

## Код

Скетч сначала разряжает конденсатор (5 с), затем подаёт «1» и 5 секунд записывает напряжение каждые 20 мс. Открой «Плоттер по последовательному соединению» — увидишь кривую. В конце скетч сам найдёт τ — время, за которое напряжение дошло до 63 % от установившегося.

```cpp
// Лаба 2: зарядка RC-цепи и измерение постоянной времени. Arduino Uno и ESP32.
#if defined(ARDUINO_ARCH_ESP32)
const int OUT_PIN = 25;              // ESP32-S3: GPIO25 нет — возьми 5
const int ADC_PIN = 34;              // ESP32-S3: 4 (ADC1)
float readVolts() { return analogReadMilliVolts(ADC_PIN) / 1000.0; }
#else
const int OUT_PIN = 7;
const int ADC_PIN = A0;
float readVolts() { return analogRead(ADC_PIN) * 5.0 / 1023.0; }
#endif

const int N = 250;          // 250 точек по 20 мс = 5 с
float u[N];

void setup() {
  Serial.begin(115200);
  pinMode(OUT_PIN, OUTPUT);
}

void loop() {
  // 1. Разряд: на выходе «0», ждём 5 τ
  digitalWrite(OUT_PIN, LOW);
  delay(5000);

  // 2. Заряд: подаём «1» и пишем кривую
  unsigned long t0 = millis();
  digitalWrite(OUT_PIN, HIGH);
  for (int i = 0; i < N; i++) {
    u[i] = readVolts();
    Serial.print("U:");
    Serial.println(u[i], 3);
    while (millis() - t0 < (unsigned long)(i + 1) * 20) {}
  }

  // 3. τ — момент, когда напряжение дошло до 63,2 % от конечного
  float uEnd = u[N - 1];
  float target = 0.632 * uEnd;
  int k = 0;
  while (k < N && u[k] < target) k++;
  Serial.print("# Uкон = ");
  Serial.print(uEnd, 2);
  Serial.print(" В, tau = ");
  Serial.print(k * 20);
  Serial.println(" мс");

  delay(3000);
}
```

## Измерь и заполни

| | Расчёт | Измерение |
|---|---|---|
| τ, с | 1,0 | |
| U через τ, % от конечного | 63 | |
| U через 3τ, % | 95 | |

## Разбор

- Почему конечное напряжение у Uno может быть не ровно 5 В: опорное АЦП — само питание, оно «плавает» вместе с USB.
- Если τ получилась сильно больше расчёта, проверь, не перепутан ли конденсатор и не стоит ли вход АЦП на делителе (он добавляет параллельное сопротивление).
